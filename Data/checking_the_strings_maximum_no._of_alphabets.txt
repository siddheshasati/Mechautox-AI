Below is a simple Python script that uses the built-in `isalpha()` function in combination with a loop to iterate over each character in the string and count the number of alphabets.

```python
def count_alphabets(string):
    """
    This function counts the maximum number of alphabets in a given string.
    
    Parameters:
    string (str): The input string for which the number of alphabets needs to be counted.
    
    Returns:
    int: The maximum number of alphabets in the string.
    """
    max_alphabets = 0
    current_alphabets = 0
    
    for char in string:
        # Check if the character is an alphabet
        if char.isalpha():
            current_alphabets += 1
            # Update the maximum count if the current count is higher
            max_alphabets = max(max_alphabets, current_alphabets)
        else:
            # Reset the current count if a non-alphabet character is encountered
            current_alphabets = 0
    
    return max_alphabets

# Example usage:
string = "Hello, World! This is a sample string with multiple alphabets."
print("Maximum number of alphabets in the string:", count_alphabets(string))
```

In this script, the `count_alphabets()` function takes a string as input and uses a loop to iterate over each character in the string. It checks if each character is an alphabet using the `isalpha()` function. If a character is an alphabet, it increments the `current_alphabets` count and updates the `max_alphabets` count if the current count is higher. If a non-alphabet character is encountered, it resets the `current_alphabets` count to 0. Finally, it returns the `max_alphabets` count.

You can replace the example string with your own string to check the maximum number of alphabets.
